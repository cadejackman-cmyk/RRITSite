Questions

Common questions

Should we move our server to the cloud?

Sometimes. If people need it from multiple places, usually yes. If it's a file server everyone uses from one building, moving it often makes things slower and adds a monthly bill. We look at each one and give you a straight answer.

Our server is old. How worried should we be?

It depends less on its age than on what happens if it stops. If it holds everything, parts are hard to get and you'd be down for days, that's a real risk regardless of how well it's running today.

We have backups on the server itself. Is that enough?

No. Setups that survive a failed drive don't protect you from someone deleting files, or from ransomware - those get copied straight through. You need a separate backup too. More on backup.

Can you support equipment someone else installed?

Yes, that's most new clients. We document what's there first, since inherited setups usually have surprises in them.
