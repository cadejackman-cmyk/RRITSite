Talk to us about your shop floor

The system that can't go down

For a manufacturer it's usually ERP. If it's down you can't receive material, release work orders, ship or invoice. For a contractor it's the plan room and the accounting system.

Either way we treat what it runs on accordingly: monitored constantly, updated only in windows you've agreed, and backed up with a recovery time that matches what an outage actually costs you. If the software is hosted by the vendor, the priority shifts to backup internet and reliable logins - which is where those setups usually fail.

Sites come and go. That should be routine.

A project starts, a trailer arrives, ten people need to work - and eighteen months later it all moves to the next job. We treat setup and teardown as a standard job with a standard kit: connectivity, network, devices and logins in one visit, everything reclaimed at the end. Each site is faster than the last.

Questions

Common questions

Can you get internet to a site with nothing there?

Almost always - usually cellular with a properly mounted antenna, sometimes fixed wireless or satellite. We check the location first, because the difference between a hotspot and a proper setup is usually the difference between usable and useless.

Can the trailer reach the office server?

Yes. We link them so the trailer works as if it were in the office. If a particular program would be painful over a cellular link, we'll say so and suggest a better option.

Can you separate the network without stopping production?

Yes. We build the new setup alongside the old one and move equipment across in small groups, using scheduled downtime or changeovers. We never attempt it in one big cutover.

We have machines running very old software. What can we do?

Wall them off. The machine goes on its own isolated zone with no internet access and only the specific connections it genuinely needs, plus a backup of its settings so it can be restored rather than rebuilt from memory.

Do you support phones and tablets in the field?

Yes - set up centrally, encrypted, and wipeable if one goes missing, with logins tied to individuals rather than one password everyone knows.
